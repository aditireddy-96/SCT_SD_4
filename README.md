# Web Scraper - Product Information Extraction

## Objective
Extract product information such as product names, prices, and ratings from an e-commerce website and store the data in a CSV file.

## Features
- Extracts product names
- Extracts product prices
- Extracts product ratings
- Saves data to CSV format

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas

## How to Run

python web_scraper.py
